# 0006 技术形态：从看图到可验证规则

## 学习目标

这节课不要求你背更多形态名称。完成后，你应该能把任何一张图上的“像箱体、像回踩、像反转”拆成：

```text
背景 → 几何结构 → 触发 → 失效 → 风险与退出
```

这直接服务于你的 `MISSION.md`：把你已有的箱体突破、均线回踩、杯柄和反转想法，变成能等待、能记录、能统计的交易假设，而不是临场找理由。

## 为什么现在学这个

你最近在 SNDK 的 4 小时图上讨论了“小震荡区 → 跌破 → 反抽失败 → 加仓”。这个思路本身有结构，但有一个常见陷阱：先凭视觉把红框叫作箱体，价格随后跌破后才倒过来确认它是箱体。

技术形态学习的第一步不是预测，而是区分三种状态：

| 状态 | 含义 | 可以做什么 |
| --- | --- | --- |
| 观察 | 结构还不完整，只是值得关注 | 标注、截图、写下条件 |
| 候选 | 结构轮廓已出现，但没有触发 | 等待，不因“怕错过”提前加仓 |
| 确认 | 预先定义的触发已完成 | 按已定义的风险规则执行或纸上记录 |

把候选误当确认，是冲动交易最常见的入口之一。

## 一、形态不是预测器

形态只是在描述价格过去如何运动。它不能自动说明下一步一定涨或跌。

同一个“小箱体”至少可能有三种后续：

```text
向下突破并被接受 → 趋势延续
向下假跌破后收回 → 反转或继续震荡
继续留在箱体内 → 结构尚未完成
```

所以，正确的问题不是“它是什么形态”，而是：

```text
若它真是这个形态，价格接下来必须完成什么行为？
若没有完成，我何时承认自己的假设不成立？
```

## 二、先把常见形态分成三族

先按“市场正在解决什么问题”分类，比背几十个名字更有用。

| 形态族 | 例子 | 它提供的主要信息 | 不能单独提供的信息 |
| --- | --- | --- | --- |
| 趋势延续 | 均线回踩、突破回踩、旗形、箱体顺势破位 | 原趋势可能暂停后继续 | 具体进场与止损 |
| 平衡／震荡 | 小箱体、三角形、收敛区间 | 买卖双方暂时平衡，等待方向选择 | 突破方向一定是什么 |
| 衰竭／反转候选 | 三推楔形、假突破、头肩结构 | 原趋势可能减弱 | 反转一定发生、目标一定很远 |

对你当前的系统来说：

```text
均线回踩、突破回踩、箱体顺势破位：趋势延续
三推后局部破位、反抽失败：衰竭反转候选
小震荡区：先是平衡；只有方向确认后，才归入延续或反转
```

## 三、每张图都用“五问法”

### 1. 背景：这个形态出现在哪里？

同样的结构，出现在不同位置，含义完全不同。

- 是上涨／下跌趋势中间的停顿，还是趋势末端？
- 是否靠近前高、前低、均线、长期箱体边缘？
- 大周期和入场周期分别是什么？

背景只能决定你要不要观察，不能直接替代入场。

### 2. 几何：边界来自价格，还是来自想象？

以小震荡区为例，至少需要写清：

```text
周期：
上沿：哪一个实际高点或价格区间？
下沿：哪一个实际低点或价格区间？
持续：至少多少根已收盘 K 线？
```

均线、趋势线可以是背景共振，但不能因为它们恰好在附近，就自动充当箱体边界。边界应首先来自实际价格反复受阻或承接的位置。

### 3. 触发：什么事件把候选变成确认？

一个可回测的空头箱体破位触发，可以写成：

```text
先有已定义的小震荡区；
一根完整 K 线收盘低于下沿；
随后反抽接近下沿，但收盘仍未回到箱体内；
再出现预先定义的向下确认后，才允许执行。
```

其中“接近”“再确认”仍需由你的系统规定，不能在交易进行中修改。

### 4. 失效：哪一个价格行为证明你看错了？

失效不是“我不舒服了”。它应该是结构本身被否定，例如：

```text
跌破后重新收回并站稳箱体内；
反抽突破失败高点；
均线回踩后收盘跌破你定义的结构低点。
```

### 5. 风险与退出：错了亏多少，对了怎么管理？

止损位置先由失效点决定，仓位再按风险金额反推：

```text
计划风险金额 = 入场价与止损价的距离 × 数量
```

同样，退出规则必须在形态完成前写下。`首次触及均线退出`、`到最近结构位减仓`、`反抽失败后跟踪` 都可以作为研究对象，但不能事后只保留对自己有利的解释。

## 四、小震荡区的最低判定标准

没有全球统一的“至少几根 K 线才算箱体”。你需要为自己的系统固定一个门槛，再用样本检验它。

一份可执行的初版定义可以包含：

1. 使用固定周期，例如 4 小时；
2. 连续 `N` 根**已收盘** K 线主要在同一上沿、下沿之间；
3. 价格至少展示过上沿受阻和下沿承接，而不是单边冲到一个新位置后刚刚停住；
4. 区间宽度不能由一根异常长影线单独决定；
5. 在真正跌破／突破前，把上沿、下沿、触发、失效写进截图或日志。

如果只看到一段急涨或急跌后两三根 K 线停顿，最准确的标签通常是：

```text
潜在小震荡区，未确认。
```

这不是错过机会，而是保留判断质量。

## 一个最小练习：用你当前的 SNDK 图练习

不要先判断它会不会跌。请用同一张 4 小时图填写：

```text
1. 背景：下行 MA169 下方的反抽／其他？
2. 候选上沿：来自哪一个实际价格高点，而不是均线本身？
3. 候选下沿：来自哪一个实际价格低点？
4. 已收盘 K 线是否足够形成平衡，还是仍是单边反抽后的停顿？
5. 什么收盘行为算有效跌破？
6. 什么收盘行为算反抽收不回？
7. 若收回箱体内，加仓计划如何取消？
8. 加仓后，原仓与新增仓的总风险是多少？
```

第 4 题如果答不出“已经形成”，正确答案就是继续标为观察，而不是强行归类。

## 自测

1. 为什么均线不能自动作为小箱体的上沿或下沿？
2. 为什么只有影线跌破，通常不足以定义为有效破位？
3. “候选形态”和“确认形态”最大的执行差别是什么？
4. 为什么加仓也必须有独立的触发、失效与风险计算？

## 接下来的学习顺序

建议按下面的顺序学习，而不是同时把所有形态加入实盘：

1. 箱体：边界、有效破位、反抽失败；
2. 趋势中的均线回踩：背景、确认 K、结构止损；
3. 杯柄和旗形：收敛与突破接受；
4. 三推楔形与假突破：衰竭背景和反转确认。

每学一个形态，先收集纸上样本；只有触发、失效、风险和退出全部明确后，才可以作为独立 setup 统计。不要为了“学习更多形态”增加实盘交易次数。

## 风险提醒

本课只用于学习、研究和模拟验证，不构成个性化投资建议。技术形态是图表观察框架，不保证方向或收益；任何研究都应纳入手续费、滑点、仓位、相关性和最大回撤评估。
