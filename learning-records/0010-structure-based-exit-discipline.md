# 结构化退出纪律

用户在 2026-08-17 复盘 HYPEUSDT 多单时识别到：单根较大阴线本身不等于结构失效；若前期低点尚未跌破，不能只因恐惧而提前离场。同日的再介入多单又在未触及初始止损时因“接近止损”主动离场，说明再介入规则与主动退出条件都必须在入场前写清，并通过纸上样本验证，避免用事后走势判断一次离场是否正确。

2026-08-19 的 MU 多单补充了另一类退出问题：入场927.72、初始止损869、后上移至903，持仓期间最高到1033，但最终以934.5出场、实际净利6.65U（+0.11R）。最高价相对入场的理论最大有利价格差约105.28U（+1.79R），但这不是自动应当拿到的利润，也不能单凭这一笔反推出最优退出法。后续同类交易需在入场前记录：第一目标或分批条件、趋势失效的结构条件、可容许的浮盈回撤定义，以及触发后具体执行方式；累积样本后再比较固定目标、结构退出与移动止损的实际差异。
